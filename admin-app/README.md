# Magazin Online Admin

Admin UI built with React, Vite, Tailwind CSS, and Supabase.

## Start

1. Install dependencies:
   `npm install`
2. Create a local env file and add Supabase values:
   - Copy `.env.example` to `.env.local`
   - Fill in `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`
3. Run the dev server:
   `npm run dev`

## Build

- `npm run build`
- `npm run preview`

## Notes

- Supabase client reads `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`.
